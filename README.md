# ipro2-lab01

Интернет программчлал II, Хичээл 1 лаборатори (NestJS).

## Суулгах

```bash
npm install
```

## Ажиллуулах

```bash
npm run start:dev
```

Сервер `http://localhost:3000` дээр ажиллана.

## Endpoint-ууд

| Endpoint | Тайлбар |
|----------|---------|
| GET /greet | Мэндчилгээ JSON буцаана |
| GET /greet/:name | Нэрээр нь мэндчилнэ |
| GET /info | Нэр, оюутны код, бүлэг буцаана |
| GET /calc?a=5&b=3 | Нийлбэр, ялгавар, үржвэр буцаана |
